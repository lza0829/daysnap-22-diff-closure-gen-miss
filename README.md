# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

```bash

cd backend && pip install -r requirements.txt

cd frontend && npm install && npm run dev
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |

| 旁置簿 | 未入账载荷 |

## 回放处置（已实现 · 口径：快照权威工单）

`回放权威择定` 已启用，全局唯一口径 **快照权威工单**（回放永不静默改镜）：

- 回放检出差额（含缺当日快照）时，**差额行 + 回放批次 + 纠偏工单在同一事务内同票同成败**，禁止只回差额数字；
- 回放事务绝不 `UPDATE 周期快照`；处置事实落不可变 `纠偏工单`（检出快照余额/回放余额/差额冻结）；
- 再次回放仍报差额，直至 **人工核账闭环**（按工单修正镜+盖写审计）或 **同日抽取盖写自动闭环**；
- 回放与同日抽取经日级作业闸互斥，交错即失败闭（HTTP 409），同票回滚、无半截改镜；镜的每次改动落 `盖写审计`；
- 只读接口 `GET /api/回放处置/{批号}`：批号、`是否改镜`（恒 false）、工单集合、`valid`——与「回放权威盖写」口径的镜变化结果明确可区分。

夹具：`fixtures/回放差额样例.json`（人为改镜造差额：甲核账改回/二次回放通过，乙不动/工单可查/二次回放仍差额）、`fixtures/回放抽取并发样例.json`（并发失败闭）。测试：`cd backend && pytest`（8 项，断言回放后镜是否变化、同票回滚、409 互斥）。
